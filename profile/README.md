## 🎯 What this is about

This toolkit turns documentation into a **first-class artifact**:

* consistent across environments
* versioned and testable
* easy to maintain and extend

## Relationship to docToolchain

This toolkit is not intended to compete with docToolchain.

[docToolchain](https://github.com/docToolchain) is a mature Docs-as-Code
toolchain for building, converting, publishing, and integrating technical and
software architecture documentation. It is especially strong when teams need
reliable generation pipelines for formats such as HTML, PDF, DocBook, DOCX,
EPUB, static sites, or Confluence publishing.

The architecture-knowledge-toolkit has a different focus. It defines reusable
architecture knowledge structures: semantic contracts, metadata conventions,
artifact templates, traceability relations, review workflows, and AI-assistable
skills for architecture work.

In short:

* docToolchain helps teams publish architecture documentation.
* architecture-knowledge-toolkit helps teams structure, relate, review, and
  evolve architecture knowledge.
* Both approaches can be combined: this toolkit can provide structured AsciiDoc
  sources and metadata, while docToolchain or similar tools can render and
  publish the resulting documentation.

The toolkit deliberately stays publishing-toolchain-friendly. Generated
documentation is treated as a derived artifact, while reviewed source
documents, metadata, and relations remain the authoritative architecture
knowledge base.

**We operate one layer above publishing.**
